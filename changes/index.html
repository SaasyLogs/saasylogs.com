Saasy Logs What works today

What has changed

Every release, newest first. The version matches the one in the add-on's About box, so if something looks wrong you can say which one you were on.

Being worked on

The homepage keeps the list: what works today, what's next, and what's wanted later.

Known, and not fixed yet

  • Very large logs. Logs over about 10 MB may not finish inside Google's 6-minute limit for a single run.
  • One log at a time. When a save hands work to a future, queueable or batch job, that work is in a different log, and the two aren't joined up yet.
  • The object path isn't built yet. The code path shows which trigger fired what; which records were touched, in order, is next.
  • Limits in other languages. If your org isn't set to English, the limits table says it couldn't read the numbers rather than showing them.
  • The scrub has no settings. It always replaces the text of debug statements whole, even when that text is what you wanted to send.
  • Shared filters. Two people filtering the same Trace tab at the same time change each other's view. A filter view you make in Sheets (Data → Filter views) is yours alone.

v0.11.1 3 October 2026 · 4a6091e

Fixed

  • The scrubbed copy now removes personal details from rule filter conditions, such as a contact's name or an account name. Names of things you configured, like profiles and record types, stay, so the log keeps its context.

Changed

  • Account names are treated as personal data in the scrubbed copy, alongside contact names and emails.

v0.11.0 3 October 2026 · a43dd5d

New

  • Big logs run about three times faster. A 25 MB log went from 136 seconds to 44: the log is compressed before it is sent, and the scrubbed copy is written at the same time as the analysis instead of after it.
  • The Summary ends with a Run time line saying how long each part took, matching what the dialog shows.
  • The code path and the method table give each value its own column: kind, how many times it ran, total time and object; calls, self time, total time, SOQL and DML.

Changed

  • Times in the tables stay in milliseconds (174,256 ms rather than 174.26 s), so a big number looks big next to a small one.
  • The Summary and Trace tabs end where their data does, with no spare rows and columns.
  • File sizes count the way your Mac does, so the dialog and Finder agree.
  • The About box fits without scrolling and links to this page.

v0.10.0 2 October 2026 · d11bb29

New

v0.2.1 25 September 2026 · 8b335f6
