**See the route your transaction actually drove.** Paste a Salesforce Apex
debug log into a Google Sheet and get back every trigger, flow, workflow rule,
validation and class it hit, in the order it hit them — with a ranked diagnosis
instead of a data dump.

It never invents a number. If a duration wasn't measured it isn't shown, and if
Salesforce threw away part of the log it says so before it says anything else.

Free. No Drive permission — it can only see the spreadsheet you opened it from,
there's no server behind it, and nothing is stored once the run finishes.
